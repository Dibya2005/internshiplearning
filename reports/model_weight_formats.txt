WEIGHT FORMET AND QUANTIZATION
PART 1: DATA TYPES (PRECISION)
Neural networks are essentially giant collections of numbers (weights). The format 
of these numbers dictates how much memory the model requires and how fast it runs.

1. FP32 (32-bit Floating Point)
   - "Single Precision." This is the standard, default data type used when training 
     deep learning models. 
   - It stores decimal numbers with high accuracy but takes up 4 bytes of memory 
     per weight. It is computationally heavy and requires massive GPU VRAM.

2. FP16 (16-bit Floating Point)
   - "Half Precision." This format cuts the memory requirement in half (2 bytes 
     per weight) by reducing the decimal accuracy slightly.
   - It is the industry standard for most inference and fine-tuning today because 
     it provides nearly identical performance to FP32 but runs twice as fast and 
     uses half the VRAM.

3. INT8 (8-bit Integer)
   - This format converts continuous decimal numbers (floating points) into whole 
     numbers (integers) between -128 and 127. 
   - It takes up only 1 byte per weight. This requires a mathematical translation 
     process called "Quantization," which compresses the model by 4x compared to FP32.

4. INT4 (4-bit Integer)
   - Extreme compression. It uses only half a byte per weight, allowing massive 
     models (like Llama 3 8B) to fit into standard laptop memory. 
   - While it introduces a slight drop in accuracy, modern quantization algorithms 
     (like GPTQ, AWQ, or bitsandbytes) minimize this loss brilliantly.


PART 2: FILE FORMATS
These are the actual file extensions used to save the weights to a hard drive.

1. safetensors (.safetensors)
   - Developed by Hugging Face, this is the modern standard for saving AI models.
   - Unlike the old Python Pickle (.bin) format, safetensors cannot execute 
     malicious code, making it 100% safe to download. 
   - It also allows for "zero-copy" loading, meaning it loads into RAM/VRAM much 
     faster than older formats.

2. GGUF (GPT-Generated Unified Format)
   - A file format specifically designed for running Large Language Models on CPUs 
     and consumer hardware (popularized by the llama.cpp project).
   - It packages the model weights, the tokenizer, and all configuration settings 
     into a single, easily shareable file. It is highly optimized for storing 
     quantized weights (INT8, INT4).


PART 3: WHY QUANTIZED MODELS ARE USEFUL ON LOW-RESOURCE COMPUTERS
Quantization (converting FP32/FP16 models down to INT8 or INT4) is the ultimate 
equalizer in modern AI. It is highly useful for low-resource computers for three 
reasons:

1. VRAM/RAM Reduction: A 7-Billion parameter model in FP16 requires ~14GB of RAM. 
   That same model quantized to INT4 requires only ~4GB, allowing it to run on a 
   standard Mac or Windows laptop instead of a $10,000 server GPU.
2. Inference Speed: Moving data from the hard drive to the CPU/GPU is often the 
   slowest part of AI. Smaller INT4 files transfer much faster, resulting in 
   faster token generation (reading/writing).
3. Lower Power Consumption: Integer math is computationally cheaper than floating-
   point math, meaning it drains less battery and generates less heat on edge 
   devices (like smartphones or Raspberry Pis).
