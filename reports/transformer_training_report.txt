# Transformer Training Report

**Project:** Text Classification using Transformers

## 1. Model Used

* **Model Name:** prajjwal1/bert-tiny
* **Model Type:** Lightweight BERT Encoder
* **Framework:** Hugging Face Transformers
* **Reason for Selection:** Chosen instead of DistilBERT to reduce training time and memory consumption while maintaining good classification performance.

---

## 2. Dataset Used

* **Dataset Location:** data/processed_dataset_1
* **Dataset Splits:**

  * Train Set: 28,544 samples
  * Validation Set: 3,172 samples
  * Test Set: 2,000 samples
* **Input Column:** text
* **Label Column:** label
* **Maximum Sequence Length:** 128 tokens

---

## 3. Hyperparameters

* **Epochs:** 3
* **Batch Size:** 16
* **Learning Rate:** 2e-5
* **Maximum Sequence Length:** 128
* **Evaluation Strategy:** Epoch
* **Save Strategy:** Epoch
* **Best Model Metric:** F1 Score

---

## 4. Training Process

* Loaded the preprocessed dataset from disk.
* Tokenized text data using AutoTokenizer.
* Loaded the pretrained bert-tiny model using AutoModelForSequenceClassification.
* Fine-tuned the model on the training dataset.
* Evaluated the model after each epoch on the validation dataset.
* Saved the best-performing checkpoint.

## 9. Conclusion

The prajjwal1/bert-tiny model was successfully fine-tuned on the Enron Spam Classification dataset. The model achieved an accuracy of 97.75% and a macro F1 score of 97.75% on the test set, demonstrating strong performance in distinguishing spam and ham emails.

The validation performance improved steadily across epochs, indicating successful learning without significant overfitting. Despite being a lightweight transformer with only approximately 4.4 million parameters, bert-tiny delivered excellent classification performance while remaining computationally efficient for CPU-based training.

The trained model, tokenizer, evaluation metrics, confusion matrix, and training artifacts were successfully saved and can be used for future inference and deployment tasks.
