EXECUTIVE SUMMARY

This report compares model performance between Dataset 1 (Enron Spam, Binary)
and Dataset 2 (AG News, 4-Class).

• Classical baselines achieved approximately 91% accuracy on AG News.
• Transformer (BERT-tiny) achieved 91.42% accuracy on AG News.
• The best-performing model on AG News was BERT-tiny, although the margin
over Linear SVM was very small.
• The experiment demonstrates that both classical machine learning and
transformer-based approaches can perform competitively on news
classification tasks.

KEY INSIGHTS

• News categories contain distinctive vocabulary, making them highly suitable
for TF-IDF-based approaches.

• Linear SVM and Logistic Regression performed nearly identically, indicating
that the feature representation was highly effective.

• Random Forest lagged behind linear models, suggesting that sparse TF-IDF
features are better handled by linear classifiers.

• BERT-tiny slightly outperformed all classical baselines, showing that
contextual language understanding provided a small but measurable benefit.

• The small performance gap (0.20%) between BERT-tiny and Linear SVM suggests
that AG News is not a highly complex semantic classification problem.

CONCLUSION

All classical machine learning baselines and the transformer model were
successfully trained and evaluated on the AG News dataset.

Among the classical approaches, Linear SVM achieved the highest accuracy
(91.22%), closely followed by Logistic Regression (91.13%). The transformer
model (BERT-tiny) achieved the best overall performance with 91.42% accuracy.
